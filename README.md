# 🥗 ПП-бот — трекер калорий в Telegram

Telegram-бот для подсчёта калорий и БЖУ. Принимает сообщение о съеденном
продукте, ищет его в базе данных, при отсутствии — обращается к Claude API
для оценки пищевой ценности, ведёт дневник питания и считает остаток от
дневной нормы.

## Стек

- **Python** — основной язык
- **pyTelegramBotAPI** — работа с Telegram Bot API, обработка команд и сообщений
- **SQLite** — хранение дневника питания, пользовательских продуктов и дневных норм
- **Anthropic API (Claude)** — распознавание и оценка КБЖУ для продуктов, которых нет в базе
- **Регулярные выражения (re)** — парсинг пользовательского ввода (продукт + количество)

## Что умеет

- Распознаёт продукт и граммы из свободного текста ("гречка 150")
- Считает калории и БЖУ по встроенной базе продуктов (~50 позиций, включая
  бренды и готовую еду)
- Если продукта нет в базе — запрашивает оценку у ИИ и сохраняет результат,
  чтобы не спрашивать повторно
- Позволяет пользователю вручную добавлять свои продукты (`/addfood`)
- Хранит дневную норму калорий и БЖУ (`/setgoal`) и показывает остаток
- Сводка по дню с историей всех записей (`/today`)
- Навигация через reply-кнопки вместо ручного ввода команд

## Архитектура проекта

```
bot.py        — точка входа: команды, обработчики сообщений, сборка ответов
foods.py      — встроенная база продуктов (словарь + функция поиска)
database.py   — слой работы с SQLite: дневник, кастомные продукты, нормы
ai.py         — обращение к Claude API, парсинг JSON-ответа
```

Код разделён по ответственности: `bot.py` не знает деталей хранения данных
или формата запроса к ИИ — эта логика вынесена в отдельные модули.

## Как запустить локально

1. Установи зависимости:
   ```
   python -m pip install -r requirements.txt
   ```

2. Получи токен бота у [@BotFather](https://t.me/BotFather) в Telegram и
   вставь его в `bot.py` (переменная `TOKEN`).

3. (Опционально, для ИИ-распознавания) получи ключ на
   [console.anthropic.com](https://console.anthropic.com) и пропиши его в
   переменную окружения:
   ```
   # Windows (PowerShell)
   $env:ANTHROPIC_API_KEY="sk-ant-твой-ключ"

   # Mac/Linux
   export ANTHROPIC_API_KEY="sk-ant-твой-ключ"
   ```
   Без ключа бот работает нормально, просто не сможет оценивать продукты
   вне базы — их можно добавлять вручную через `/addfood`.

4. Запусти:
   ```
   python bot.py
   ```

## Команды бота

| Команда | Что делает |
|---|---|
| `гречка 150` | Записать продукт и граммы |
| `/today` | Сводка за день и остаток от нормы |
| `/addfood` | Добавить свой продукт (название + КБЖУ на 100г) |
| `/setgoal` | Задать дневную норму калорий/БЖУ |
| `/foods` | Список известных продуктов |
