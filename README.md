# ПП-бот — трекер калорий в Telegram

## Новое в этой версии
- ИИ распознаёт продукты, которых нет в базе
- Можно добавлять свои продукты (бренды, готовая еда) командой `/addfood`
- Можно задать дневную норму калорий и БЖУ командой `/setgoal`

## Как запустить

1. **Установи новые зависимости** (в терминале VS Code, в папке проекта)
   ```
   python -m pip install -r requirements.txt
   ```

2. **Получи API-ключ Anthropic** (для ИИ-распознавания продуктов)
   - Зайди на https://console.anthropic.com
   - Зарегистрируйся / войди
   - В разделе API Keys создай новый ключ (начинается с `sk-ant-...`)
   - Учти: это платный API (по факту использования), но для распознавания
     еды расходы очень маленькие — там будет что пополнить баланс

3. **Пропиши ключ в переменную окружения**

   Есть два варианта: временный (для одной сессии терминала) или постоянный.

   **Windows (PowerShell), временно — только для этого запуска терминала:**
   ```
   $env:ANTHROPIC_API_KEY="sk-ant-твой-ключ"
   ```
   Выполняй эту команду каждый раз перед `python bot.py`, если не настроишь постоянно.

   **Mac/Linux, временно:**
   ```
   export ANTHROPIC_API_KEY="sk-ant-твой-ключ"
   ```

4. **Вставь токен Telegram-бота**
   Как и раньше — в `bot.py`, строка `TOKEN = "ВСТАВЬ_СЮДА_СВОЙ_ТОКЕН"`.

5. **Запусти бота**
   ```
   python bot.py
   ```

## Как пользоваться

- Продукт и граммы: `гречка 150` — если продукта нет в базе, бот спросит у ИИ и запомнит на будущее
- `/addfood` — добавить свой продукт вручную (бренды, готовые блюда): бот спросит название и КБЖУ на 100г
- `/setgoal` — задать дневную норму: калории, и по желанию белки/жиры/углеводы
- `/today` — сводка за день + остаток от нормы, если она задана
- `/foods` — список базовых продуктов

## Структура проекта

- `bot.py` — логика бота: команды, обработка сообщений
- `foods.py` — встроенная база продуктов (можно дополнять прямо в коде)
- `database.py` — SQLite: дневник, кастомные продукты, дневные нормы
- `ai.py` — запрос к Claude API для распознавания незнакомых продуктов
- `diary.db` — база данных, создаётся автоматически при первом запуске

## Если что-то не работает

- **`ANTHROPIC_API_KEY` не найден / ошибка авторизации** — проверь, что переменная
  окружения задана в том же терминале, где запускаешь `python bot.py`
- **ИИ отвечает странно** — модель иногда ошибается в оценке, для точных продуктов
  лучше добавить вручную через `/addfood`
